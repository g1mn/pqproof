# Maintainers

| GitHub | Role |
|---|---|
| [@g1mn](https://github.com/g1mn) | Lead maintainer. Creates release tags (`v*`, which publish to PyPI) and handles security reports ([SECURITY.md](SECURITY.md)). |
| [@dreamofwing](https://github.com/dreamofwing) | Maintainer. Reviews pull requests and triages issues. |

Changes to `main` go through a pull request with one approving review. Only the lead maintainer can create release tags.
