# Maintainers

| GitHub | Role |
|---|---|
| [@g1mn](https://github.com/g1mn) | Lead maintainer. Cuts releases (`v*` tags, which publish to PyPI) and handles security reports ([SECURITY.md](SECURITY.md)). |
| [@dreamofwing](https://github.com/dreamofwing) | Maintainer. Reviews pull requests and triages issues; can cut a release when the lead maintainer is unavailable. |

Changes to `main` go through a pull request with one approving review. Admins and maintainers can create release tags; the lead maintainer normally does. See [GOVERNANCE.md](GOVERNANCE.md#continuity).
